# 🌙 마피아 — 밤이 오면

친구들과 브라우저로 함께하는 실시간 마피아 게임입니다. 사회자는 컴퓨터가 자동으로 맡아요.

- 참가 인원 **4~10명**
- 낮 **2분** (전원이 투표하면 바로 결과 발표)
- 밤은 능력자 **1명당 30초** — 마피아 → 의사 → 경찰 순서로 진행
- 인원에 맞춰 마피아·경찰·의사 수 자동 조절
- 채팅 + 이모지 (밤에는 마피아끼리만, 죽은 사람은 망자끼리만 대화)
- 새로고침하거나 연결이 끊겨도 같은 브라우저로 다시 들어오면 자리 유지

## 역할 배분

| 인원 | 4 | 5 | 6 | 7 | 8 | 9 | 10 |
|---|---|---|---|---|---|---|---|
| 🔪 마피아 | 1 | 1 | 2 | 2 | 2 | 3 | 3 |
| 🕵️ 경찰 | 1 | 1 | 1 | 1 | 1 | 1 | 2 |
| 💉 의사 | 0 | 1 | 1 | 1 | 1 | 1 | 1 |
| 🙂 시민 | 2 | 2 | 2 | 3 | 4 | 4 | 4 |

`server.js` 위쪽의 `ROLE_TABLE`, `CONFIG`에서 인원 배분과 시간을 바꿀 수 있어요.

## 규칙

1. 게임이 시작되면 각자 역할을 확인하고 첫 번째 밤이 시작됩니다.
2. **밤**: 마피아가 제거할 사람을 고르고(여러 명이면 같은 사람을 골라야 바로 확정, 아니면 다수결·동률은 무작위), 의사가 지킬 사람을, 경찰이 조사할 사람을 고릅니다. 경찰의 조사 결과는 본인 채팅창에만 표시돼요.
3. **아침**: 누가 희생됐는지 발표됩니다. 의사가 지킨 사람은 살아남아요.
4. **낮**: 2분 동안 토론하고 투표합니다. 최다 득표자가 처형되고, 동률이거나 기권이 가장 많으면 아무도 처형되지 않아요.
5. 마피아가 모두 사라지면 **시민 승리**, 마피아 수가 나머지와 같아지면 **마피아 승리**.

## 내 컴퓨터에서 실행하기

[Node.js](https://nodejs.org) 18 이상이 필요해요.

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속. 같은 와이파이에 있는 친구는 `http://내컴퓨터IP:3000`으로 들어오면 됩니다.

## 친구들과 인터넷으로 하기 (무료 배포)

GitHub Pages는 정적 페이지만 올릴 수 있어서 실시간 서버가 필요한 이 게임은 돌아가지 않아요. 대신 GitHub 저장소를 [Render](https://render.com) 같은 서비스에 연결하면 무료로 띄울 수 있습니다.

1. 이 폴더를 GitHub 저장소에 올립니다.
2. Render에 GitHub 계정으로 가입 → **New → Web Service** → 저장소 선택
3. Build Command: `npm install` / Start Command: `npm start` / Instance Type: Free
4. 배포가 끝나면 나오는 주소(`https://xxxx.onrender.com`)를 친구들에게 공유!

무료 플랜은 한동안 접속이 없으면 잠들어서, 처음 들어갈 때 1분 정도 걸릴 수 있어요.
